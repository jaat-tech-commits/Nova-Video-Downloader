# Nova Video Downloader

Native Android downloader for permitted public HTTP/HTTPS resources.

Includes URL download, Android Share integration, progress/speed, HTTP Range resume, retry/cancel, Material 3 UI and GitHub Actions APK builds.

It intentionally does not bypass DRM, authentication, paywalls or access restrictions. A generic downloader cannot legitimately support literally every website; this core handles publicly accessible HTTP/HTTPS resources.

Open GitHub Actions after a push and download the debug APK artifact.
